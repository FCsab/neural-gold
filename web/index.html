    Train and test a model

    Each bar is labelled by what happened next: price reached the target, hit the stop, or did neither in time. The model learns to predict that from past bars, then trades the newest 15% of the data it never saw. It learns from BTC/USDT history since 2017, which moves with BTC/USDC but is four times longer, and it only buys when it expects the gain to cover the fees and slippage.

      Training, live

      Updates every two seconds while a model trains. Each point is one pass over the training data (an epoch). The held-out data is never trained on, so it shows whether the model is learning something general or only memorising. When a stalled model is replaced by a fresh one, the lines jump: that is the new model starting.

      Risk model

      A neural network and a gradient-boosted model, averaged, predict the chance of a sharp fall. The rule stays long BTC and steps aside when that chance is high. It is tested on every 90-day block since 2018, each time with models that only saw the past, and set against simply holding, a no-model trend rule, and random exits. Fees and slippage are included. Takes about two minutes.

      Paper record

      Every run with the default settings writes down its reading for the next 4-hour bar, with the time it was made, before anyone knows the outcome. The first reading for a bar is kept; running again cannot change it. A reading made more than ten minutes after its bar opened is booked at the next bar. This is the record that has to agree with the test above before any real money is considered. Nothing here places an order.
