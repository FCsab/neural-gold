What this is

A research workbench for a PAXG/USDT trading model. It downloads price history, turns it into labelled examples, checks that nothing leaks future information, and trains a small neural network. It cannot place orders. There is no exchange key anywhere in it.

  1. Market data — pull historical candles from Binance.
  2. Labels & dataset — for each bar, work out what happened next: profit target, stop loss, or neither.
  3. Look-ahead check — prove the features cannot see the future. If this fails, do not train.
  4. Training — fit a model and read honest test metrics.

The strip above the tabs always tells you the next thing to do. Nothing is destructive: bars and datasets can be rebuilt at any time.

Recent trades

Tries many profit-target / stop / holding combinations, trains a model for each, and ranks them by how they would have done on validation data — history the model never trained on. Settings whose target cannot pay for the round-trip cost are skipped before any training happens, so the hours go to candidates that could plausibly work. Every result is written to disk as it lands, so you can leave it running and come back later.
